AriesTerminal is a simple TurboWarp project that allows you to easly Load/make N-Gram models. with cross-model memory and other stuff.

# Pre-made models:
- AriesRLM1.0 (Nearly sentient, "Reasoning" type)
- AriesRLM1.1 (Nearly sentient, "Reasoning" type)
# Corpuses:
- Spacecore.txt (Space Core Persona from portal 2)
- Factcore.txt (Fact Core Persona from portal 2)
- SpaceCreature.txt (Weird, Uncontroled Creature)
- Nuclear.txt (Tinyllama's Nuclear Test site speech)
- Generic.txt
- Adventurecore.txt (Adventure Core Persona from portal 2)
- AriesRLM1.0_Unchecked_Corpus.txt (Unchecked, beware of stuff)
- AriesRLM1.1_Unchecked_Corpus.txt (Unchecked, Beware of stuff)
